# 高速通用流体泵

- 等级：LV，机器 ID 28611。支持 128A LV 输入，储能保持 32768 EU。
- 合成：GT 的 LV 泵 + LV 电动泵，工作台无序合成。
- 无需采矿管。以机器为中心，抽取下方 129×129 格区域，直到 Y=0；不会破坏固体方块。
- 每轮先检查机器正下方的竖直列，发现流体后优先沿连通流体向下追踪，再向其他相邻方向扩展。石油柱连接地下油池时，无需每下降一格都扫描完整的 129×129 层面。
- 连通搜索结束后，继续按行逐层扫描其余区域，因此分散、不连通的流体也能找到。建议把机器放在油柱或流体上方，以尽快定位流体。
- 每 tick 最多检查 8192 个位置、抽取 512 个流体方块；每次成功抽取消耗 8 EU，满速最高 4096 EU/t。抽取与扫描上限均为原来的 8 倍，连通搜索与兜底扫描共享同一份预算。
- 持续满速需要提供 128A LV；供电不足时按剩余电量抽取，恢复供电后从暂停位置继续。
- 原版水和岩浆源方块产出 1000 mB；流动方块被清除但不产出流体。模组流体使用 Forge `IFluidBlock` 的实际可抽取量，不可抽取的流动格仅用于追踪连通区域，不产生额外流体。
- 支持下界岩浆，无维度白名单；不产生无限流体。水的原版自然再生规则仍然适用。
- 内置单流体缓存 16,000,000 mB（16000 桶）。缓存不足或遇到不同流体时，停在该位置等待输出。
- 默认开启自动流体输出，最高 512000 mB/t；通过 GT 原生输出面连接储罐或流体管道，GUI 可关闭自动输出。实际速度受接收端吞吐和可用容量限制。
- 只扫描已经加载的区块，不强制加载。每轮结束后等待 5 秒再扫描，因此稍后加载的区块会在下一轮被检查。
- 遵守 Forge 方块破坏事件；禁止假玩家抽取的领地会被跳过。流体缓存、扫描进度与待处理的连通搜索队列随世界存档保存；断电或输出阻塞时保留当前抽取位置。

## 开发验证

`scripts/universal-pump-qa.init.gradle` 在独立的 `run/universal-pump-qa` 目录使用一次性测试世界验证竖直油柱、连通搜索与分散流体、真实水/岩浆消耗、下界、模组流体量、跨行批次上限、范围边界、断电/满缓存/混合流体保护、领地事件、NBT 重载、高速输出及原生 GUI。Windows 测试客户端由专用辅助脚本保持透明、鼠标穿透且不显示任务栏。

Windows 本地 Java 若出现 loopback connection 错误，可设置 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:/Windows/Temp`，再运行 `gradlew.bat -I scripts/universal-pump-qa.init.gradle runClient --no-configuration-cache --console=plain`。
