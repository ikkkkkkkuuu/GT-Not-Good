# ME 容器

用 AE 线缆连接，需网络供电与一个频道。右键打开界面，物品、流体各有 36 个虚拟配置槽，支持从 NEI 拖入样本，也可以手持物品或流体容器点击配置；样本不消耗。空手左键清空。槽下显示网络数量缩写，悬停显示完整数量，流体单位为 mB。

- **流体抽取**：外部管道按实际请求直接从 AE 抽取，没有 16,000 mB 缓存上限。单次调用最多为 Forge 接口支持的 2,147,483,647 mB，可连续调用；界面库存使用 64 位数量。
- **物品抽取**：每个配置槽自动补充一组真实物品，兼容漏斗和管道的原版库存协议。更换配置时，旧物品仍可抽走，取完后再补充新物品。
- **外部输入**：所有方向均接受输入，输入内容不受抽取配置限制。流体直接存入 AE，返回实际接收量；物品经过独立输入缓存后入网。网络满、断电或断线时，未入网的物品留在缓存中，不会被销毁。
- **升级保存**：旧版配置迁移到第一个槽。旧流体缓存仍可抽取；生存模式拆下方块会保存配置和实际缓存，不复制 AE 网络库存。

新材质为原创 32×32 像素图：侧面显示物品、流体与双向箭头，顶面为青色接口，底面为散热格栅。

LV 装配机配方：ME 接口 ×1、箱子 ×1、玻璃 ×4、LV 电路 ×1，耗时 15 秒。
