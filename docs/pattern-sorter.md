# 手持样板分类工具

合成：空白 AE 样板＋指南针＋纸，无序合成。工具没有内部库存。

1. 将旧接口里的样板取到背包，手持工具右键。
2. 搜索并选择原机器的配方类型，如卷板机、挤压机；工具会记住选择。
3. 左边按电路编号和模具分组，右边预览该组样板的首个产物及背包位置。
4. 点击“按组整理”将同组样板排在一起；选中一组后，也可点击“此组排到前面”。
5. 从界面下方的真实背包取出样板，分别放进配置相应电路和模具的输入总成。

整理仅交换已有样板格，空格、其他物品、样板数量及 NBT 都保留。顺序为背包三行，随后快捷栏。
鼠标拿着物品时不能整理。界面不储存样板，关闭界面无需取回物品。

识别复用自动电路的输入、输出、NBT 和数量比例匹配，支持整数倍和省略副产物。
带流体的加工样板按 AE 原生 Ultimate Encoded Pattern 解码，不将流体包当成实体原料。
电路和非消耗模具应和原自动推送用法一样从样板消耗输入中省略。
多种配置同时匹配时归入“有歧义”，不自动猜选。未匹配、不支持、工作台和无效样板分别显示。
分类描述配方所需配置，不代表当前目标机器已满足电压或其他运行条件。

GUI 使用项目 LDLib 的主题、可搜索选择器与虚拟列表；真实背包和服务端同步沿用 MUI2。
物品图标为本项目原创 16×16 像素图。

## 验证

`gradlew -I scripts/pattern-sorter-qa.init.gradle test --tests '*PatternSorterTest' --no-configuration-cache`
检查数量、NBT、其他物品保留，以及旧快照和重复槽位不能覆盖物品。

`gradlew -I scripts/pattern-sorter-qa.init.gradle runClient --no-configuration-cache`
在独立临时世界验证原生流体样板、电路、模具、歧义和错误原料匹配，并实际点击两个整理按钮。
截图和通过标记输出到 `build/pattern-sorter-qa`，测试完成后自动退出。
