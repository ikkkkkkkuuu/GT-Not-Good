# 通配符样板的 NEI 导入

1. 手持通配符样板右键打开配置界面，再从 NEI 查询配方。
2. 点击配方旁的「＋」，自动填写输入、输出和数量，并返回输入页。
3. 检查通配项、固定辅料及过滤条件，点击「保存」写入样板。

所有能识别的材料矿辞会转换为对应前缀通配项，包括附加材料；可识别的材料流体转换为流体状态通配项，数量按 mB 保留。电路、不可消耗的模具等样本保持固定，所需样本数量记为 1；无法识别的物品或流体保持固定。携带额外 NBT、无法由通配项保留的数据也保持固定。

导入替换当前输入、输出草稿，保留已有过滤条件。所有通配项沿用样板现有的同一材料轴；导入不保证每个展开结果都存在对应的机器配方。

支持 GT 加工配方与熔炉配方。每侧最多 6 项，物品与流体合计；超限、概率产出、缺少输入输出及不支持的配方会禁用「＋」，悬停可查看原因。
