# 奥术工作台封包

## 使用

1. 用基础封包核心与奥术工作台无序合成「奥术工作台封包核心」，装入封包供应器。
2. 连接器正常右击供应器，再 Shift 右击奥术工作台完成绑定。
3. 在工作台摆好一次配方；背包携带空白样板。
4. 打开供应器的连接列表，左击对应工作台行。样板自动放入供应器的空样板槽。
5. 清空工作台九宫格，保留法杖/权杖，关闭工作台界面，然后从 AE 下单。

录入不消耗示例材料。每个非空格按一次配方所需的一个物品记录；重复材料和空格位置完整保留。
普通加工样板没有九宫格记录，不能直接用于此核心。样板不能倍乘，也不启用材料替换。
所有者须在同维度在线，并有权操作工作台；执行时重新核对研究及真实配方产物。

## Vis 与源质

优先使用台上法杖的 Vis。只补本次合成实际缺口，保留法杖及玩家装备的原生消耗修正。
需要时从供应器所在 AE 网络抽取对应基础源质（需要神秘能源以及可用的源质存储）。
复合源质不拆分。每次配方的折扣后消耗仍不得超过法杖容量。

配置：`Thaumcraft.arcaneVisPerEssentia`，默认 `1`，范围 `1..1000`。
一单位对应基础源质默认转换为一显示点 Vis，即神秘时代内部的 100 单位。
源质按整数抽取，未用完的百分之一点余量保存在供应器 NBT，供后续任务使用，不凭空丢弃。
如果存储在模拟之后只提供部分源质，已取得部分也作为持久化额度保留，下一次不会重复收费。
额度属于供应器，不跟随法杖或核心移动；拆除供应器会丢弃额度。

缺材料、配方不匹配、无权限、法杖容量不足、工作台被占用或回收栏无法容纳全部结果时不执行。
先模拟所有缺少的基础源质再抽取，普通缺货不会扣除其他属性。法杖扣费先在副本上通过原生 API 验证。

## 输出与速度

成品与合成容器（例如桶）一起进入供应器持久化回收栏，再送入 AE；网络拒收则保留在回收栏。
这是同步工作台合成，直接回收结果，无需祭坛的「自动回收」开关，也不会等待祭坛的每秒轮询。
原版工作台结果槽是预览，不能把它当成已完成产物抽走。

每个供应器绑定的每张工作台每 tick 至多执行一次配方；多张工作台可以并行。
20 TPS 下每次产出 1 个时，1000 个理论需要 1000 tick（50 秒）；每次产出 4 个则需要 250 tick。
实际速度还取决于服务器 TPS、AE CPU 派单和网络供料。供应器每次派单最多检查 16 个目标，避免无界扫描。
