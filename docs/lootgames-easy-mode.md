# LootGames 内置最低难度

适配当前依赖 LootGames 2.2.14。仅在加载 LootGames 时启用，在其配置初始化完成后覆盖运行时难度；不需要编辑整合包配置，配置重新加载后仍会生效。

| 游戏 | 内置设置 |
| --- | --- |
| 记忆灯光 | 初始 1 个符号，每阶段 1 轮，四阶段依次记忆 1–4 个符号；不随机重排，不扩展棋盘；每个符号显示 40 tick（2 秒）；关闭失败爆炸、僵尸和岩浆 |
| 扫雷 | 四阶段均为半径 2（5×5）棋盘、1 颗雷，启用无猜测生成；引爆等待 600 tick（30 秒） |
| 数独 | 四阶段均为 0 个空格，按原版操作提交答案即可；启用所有提示，错误提交仅清除错误格 |

三种游戏的尝试次数均设为原生允许的最大值 `2147483647`。灯光空闲超时为 `107374182` 秒，避免转换为 tick 时整数溢出。

## 最高奖励

三种游戏进入原生奖励结算时，均生成 4 个宝箱，每箱使用该游戏第四阶段奖池（保留按维度配置的奖池覆盖）。普通宝箱的 27 格逐格生成奖励，每格填至物品和容器允许的堆叠上限；不可堆叠物品仍为 1 个。保留奖池权重、NBT 和 Forge 自定义生成钩子，物品种类仍随机。

不以反复随机写入同一箱子的方式增大奖励，避免物品互相覆盖。无效空奖池继续走 LootGames 原生错误处理；自定义钩子返回空结果时不凭空补物品。没有进入奖励结算的失败不强行发奖，已生成的奖励箱也不会被修改。

扫雷、数独的难度会在棋盘生成时保存到 NBT。新的最低难度适用于新生成的棋盘；已有棋盘保留保存的布局与难度快照，避免破坏正在进行的游戏。灯光配置以及扫雷全局尝试次数直接使用新的运行时设置。

实现仅修改配置值，不复制上游代码或资源。对照来源：GTNewHorizons/LootGames 2.2.14 的 `ConfigGOL`、`ConfigMS`、`ConfigSudoku` 及相应游戏逻辑。
