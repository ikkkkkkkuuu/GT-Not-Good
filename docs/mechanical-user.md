# 使用者

无需能量的普通方块，工作面朝向放置者，支持六个方向。右键打开界面。
九个物品槽支持漏斗和管道输入、输出；右侧独立槽只接收使用者速度升级。

三个按钮依次切换操作模式、模拟左／右键和随机非空槽位／仅左上角槽位。

| 模式 | 右键行为 |
| --- | --- |
| 一般点击 | 点击前方方块；前方为空气时使用物品 |
| 放置方块 | 将方块放到紧邻工作面的可替换位置 |
| 在方块上使用物品 | 调用工具的方块使用行为，例如锄地 |
| 用物品激活方块 | 调用前方方块的激活行为，例如用打火石激活 TNT |
| 使用物品 | 调用物品的右键行为，例如投掷喷溅药水 |
| 实体交互 | 对前方一格内的非玩家实体右键，例如剪羊毛 |

左键在实体模式中使用手持物品攻击；方块模式中执行一次普通左键点击。
不提供持续按住鼠标的动作，因此不会持续挖掘硬方块、拉弓或完成食物的食用时间。
模拟玩家名为 `[GTNGUser]`，遵循 Forge 交互事件，目标模组仍可拒绝假玩家操作。
默认每 20 tick 操作一次；每个速度升级减少 1 tick，最低每 tick 一次。
工具耐久、消耗品和返还的桶／瓶等由真实物品逻辑处理，额外返还物优先放回缓存，满时掉落。
破坏方块会掉落库存和升级，操作设置随世界存档保存。

## LV 配方

均在 LV 装配机中制作，以 NEI 为准：

- 使用者：LV 机器外壳 ×1、LV 机械臂 ×1、LV 传送带 ×1、LV 电路 ×2、钢板 ×2；电路 1，10 秒。
- 速度升级：LV 电动马达 ×1、LV 电路 ×1、单股铜线 ×2；电路 2，5 秒。

原版纹理来源及权利声明见 `src/main/resources/META-INF/mechanical-user/NOTICE.md`。

## 验证

`MechanicalUserPersistenceTest` 检查物品提取、保存字段和无效模式边界。
`MechanicalUserClientChecks` 是仅测试类路径加载的 Forge 模组，需要系统属性
`mechanicaluser.qa=true`，使用独立的开发运行目录。自动在平坦测试世界检查放置、锄地、剪羊毛、
剑伤害，打开界面并保存游戏截图。它不会打包进发布文件。

启动命令：`gradlew.bat -I docs/testing/mechanical-user-client.gradle runClient`。
截图保存在 `run/mechanical-user-check/screenshots/`，每次测试创建独立世界。
