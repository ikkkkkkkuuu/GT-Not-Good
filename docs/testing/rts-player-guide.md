# RTS 官方分支集成版操作

当前 G 键入口已切换到官方 `forge-1.7.10` 界面。启用
`config/GTNOTGOOD/gtnotgood.cfg` 中的 `enableRTSBuilding` 后重启；本地测试端已启用。
详细设置在 `config/rts_building/`。创造模式可以直接进入，生存模式沿用官方控制核心和插件解锁。

WASD 移动镜头，右键拖动旋转，中键拖动平移，滚轮缩放，G / Esc 退出。
顶部按钮切换交互、存储绑定、建造、隐藏范围等功能；底部保留创造、存储和蓝图标签。
具体动作以原版按钮提示和按键设置为准。

构建、实机验证与尚未验收的功能见 [官方分支集成记录](rts-official-integration.md)。
这一版已经内置 RTS，不要再同时安装独立 RTS Building jar。

## 旧开发预览记录（不再是默认入口）

这是功能联调入口，尚不是上游界面和全部兼容功能的最终移植。配置需启用
`enableRTSBuilding`，客户端与服务器必须使用同一版本。更新后重启客户端；已经打开的
旧客户端不会载入新代码。

## 进入和移动

- G：申请服务器授权后进入；ESC 或右上角 X：退出并恢复原视角。
- WASD：相对镜头移动；空格/Shift：升降；右键拖动：旋转；中键拖动：平移；滚轮：缩放。
- 搜索框取得焦点时不会移动镜头。点击世界或其他控件可移出搜索框。

## 物品与单点操作

- 1–9 或底部快捷栏：切换真实手持物品。
- 点击背包列表中的物品：用原版背包交换操作将该槽物品装备到手上。不是生成物品。
- 放置模式：左键执行手持物品的原生右键操作，Shift 保留潜行使用语义。
  空手也能交互；打开容器会退出 RTS 并恢复正常界面。
- 采掘模式：左键开始一个方块的持续采掘；顶部显示服务器进度；“取消”停止。
  使用真实工具、原生挖掘速度、掉落、耐久与保护事件。不可破坏的方块会拒绝。

## 区域任务

1. 框选模式下，左键依次选择两个角，蓝框表示所选区域，最多 4096 个格子。
2. PgUp/PgDn 将已确认的选区整体上移/下移一格。铺地可框选地面后按一次 PgUp。
3. “填充选区”只填空气格，逐个使用真实手持方块；已有方块不会被覆盖。
   目标需要可点击的相邻支撑面。不能用这个入口复制机器内部数据或替代蓝图。
4. “采掘选区”从上层开始逐个挖掘已有方块，使用当前真实工具。
5. 顶部显示完成数量；暂停允许已提交的单次操作完成，之后停止提交新操作。
6. 建造会自动寻找背包中相同物品、损伤值和 NBT 的下一叠。没有材料时保留任务并暂停，
   补料后点“继续”；工具耗尽时也暂停。拒绝或不确定结果会终止任务，不自动重试。
7. “取消”清除剩余队列；退出 RTS、关闭界面或失去会话会清理任务。

GT 机器旋转：切到 RTS 的旋转模式后点选机器，再点击显示的方向弧。仅显示该机器当前允许的四分之一圈旋转；不支持上下朝向的机器不会提供非法方向。GT 朝向通过原生接口更新，保留机器实体数据。

## GTNG 内置 RTS 能力
所有 RTS 插件能力默认解锁，不需要安装插件；旧存档插件开关不再限制能力。采集无需工具，不消耗工具耐久。生存和创造模式的 RTS 采集均走方块原生掉落，并继续使用自动入库。石头掉圆石、钻石矿掉钻石，不自动附加精准采集或时运。基岩等不可破坏方块、领地权限和服务端任务预算仍保留。
