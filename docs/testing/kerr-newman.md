# 克尔-纽曼均质仪客户端验证

新增稀土粉体、矿石模式的配方、模式保存和 GUI 回归见[石化与稀土配方回归](production-simplification.md)。

执行：

```powershell
.\gradlew.bat -I scripts/kerr-newman-qa.init.gradle runClient17 --no-daemon
```

该独立世界使用工厂 QA 的隐藏、透明、穿透及静音辅助脚本。不要同时启动其他工厂 QA；
维度聚焦和装配工厂验证应各自顺序运行。运行结果写入 `build/kerr-newman-qa/result.txt`，
截图位于该目录的 `screenshots/`。只有 `PASS` 表示完整通过。

以下专项夹具记录对应模块化之前的历史基线。最终六台加工机器已统一采用默认有损超频
（耗时 ÷2、EU/t ×4）；本机保留 60 倍基础速度，参数模块覆盖对应参数。
最终模块化加工与超频验证见 [模块化多方块检查](modular-machines.md)。

历史夹具覆盖：

- 83×36×83 原版结构四向建造和成型，每类固定构件缺失及修复，所有实体输入输出舱体。
- 后方 34 格黑洞中心随朝向旋转，原生渲染边界覆盖 4.5 格视界，256 格渲染距离。
- 控制器九物品、三流体配方的原始数量、耗时、EU/t及研究门槛；23 种新增构件在工作台、组装机、
  电弧炉、精密组装机或装配线中至少一条完整生存配方，安普洛管道保留原始 3×3 工作台布局。
  进阶聚变线圈保持九槽组装机、八物品输入及无尘门槛；生物活性方块保留精密组装设施并完整展开前置成本。
- 实际原生搅拌配方的物品、流体消耗和非消耗电路；并行物品/流体产出及真实能源预算。
- 速度 6000%（60 倍）和原生完美超频。4800 tick、30 EU/t 的夹具在 LV 下耗时 80 tick；
  MV 单并行执行一次完美超频后耗时 20 tick、120 EU/t。基础速度不附加 EU/t 折扣。
  使用长耗时夹具隔离最短 1 tick 取整和亚 tick 并行；低电压多安培仍不能跨越配方电压，
  实体能源仓升级和输出保护失败后的原料保留也需通过。
  LV/MV 实测耗时、EU/t、并行、能源仓位置/电压/安培及注册配方数值单独写入 `processing-diagnostics.txt`。
- 真实控制器 TileEntity NBT 保存恢复，保留进度、耗电与待输出产物。
- 真实客户端工作、停机、重新启动、结构损坏及修复后的网络状态；原生 stream 完整往返。
- 512 个加速器线圈与 566 个进阶聚变线圈接受工作元数据 11/12，开停、破坏和移除控制器时正确同步。
- 黑洞展开/收缩截图、真实背景折射 shader 成功编译，以及原生 WorldLast 绘制后的 GL 状态恢复。
- 远景、构件近景、控制器 GUI 和中英文普通/Shift tooltip 截图。速度与完美超频说明必须与
  GTNH 原生 `addStaticSpeedInfo(60F)`、`addPerfectOCInfo()` 的本地化和语义配色一致。

该历史基线的 60 倍速度及完美超频由用户指定，属于本地性能调整；上游功能仓和闭源 GTOLib 的内部语义不能据此推定。
并行预算仍受实际供电限制，配方及来源映射详见 `reference/kerr-newman-port/RECIPE_ADAPTATION.md`。
