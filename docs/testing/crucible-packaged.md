# 坩埚封包与供应器重命名

## 使用

- 基础封包核心 + 神秘时代坩埚，无序合成坩埚封包核心。
- 将核心装入无线样板供应器。连接器普通右击供应器选择，再 Shift 右击真实坩埚绑定。
- 使用处理样板：输入一个催化剂，输出一次炼金配方的完整产物数量。水和源质不写入样板。
- 无需供水，也不消耗已有的水。坩埚须烧热；空坩埚下方有火、熔岩或神秘时代热源即可。供应器所有者须在本维度在线并完成对应研究。
- 优先消耗坩埚已有源质；缺少的源质通过神秘能源从供应器的 AE 网络补齐。
- 产物直接进入供应器回收栏，再送回 AE。回收栏满、缺源质或研究不符时不接受催化剂。
- 若坩埚已有源质会使原版选择另一配方，则拒绝派单，避免错误产物。
- 无线样板供应器现在实现 AE 自定义名称接口，可使用终端原有重命名入口；名称保存到方块 NBT。
