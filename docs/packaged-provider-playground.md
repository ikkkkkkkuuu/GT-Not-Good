# Provider / TC4 手动测试世界

启动脚本：`gradlew.bat -I scripts/packaged-playground.init.gradle runClient`。
脚本每次创建独立创造模式存档，不覆盖已有世界，不自动下单，不关闭客户端。
存档名称写入 `run/client/packaged-playground-save.txt`，之后可从单人游戏列表重新进入。
搭建器仅属于测试运行环境，不进入正式发布包；使用 TC4 原有配方，不添加测试配方。

连接器专项验证：启动命令追加 `-PpackagedConnectorQA=true`，必须使用新测试世界。
它自动截取未选择、已选择、指向新机器、收起工具、解绑和重新绑定六种状态，
校验客户端绑定列表随服务器更新，最后输出 `PACKAGED_CONNECTOR_SYNC_PASS` 并退出。
截图保存为 `run/client/screenshots/packaged-connector-1.png` 至 `-6.png`；
该专项验证不替换手动世界记录，也不启动合成。

- Provider：`0, 8, 0`，已安装 TC4 注魔核心、绑定矩阵并开启自动回收。
- 注魔矩阵：`6, 10, 0`，已激活，周围有八个对称基座。
- AE：祭坛西侧，创造能源、控制器、64k 存储元件、64k 合成存储器、合成协处理器。
- 北面三个终端：从东向西依次为合成终端、样板终端、接口终端。
- 源质罐：祭坛南侧，每种配方源质四罐，每罐 64。
- 稳定装置：地面一圈对称蜡烛，地下另有对称蜡烛层。

在 AE 合成终端搜索石英法杖杖芯（Quartz Wand Core），发起一次合成即可观察。
样板使用 TC4 原有 `WandRodQuartz` 配方；玩家已获得该配方研究，AE 已存入配方材料。
快捷栏备有连接器、注魔核心、Provider 和空白样板，方便自行修改或测试绑定。
源质会正常消耗；大量连续测试后需补充。稳定蜡烛遵循 TC4 原机制，并未关闭失稳逻辑。

## AE 源质对照组

测试运行环境额外加载 Thaumic Energistics 1.7.60-GTNH（对应当前整合包清单），正式模组不增加必需依赖。
第二套位于东侧：Provider `40,8,0`，矩阵 `46,10,0`。
它拥有独立 AE 网络、物品与源质存储元件、CPU、合成终端、源质终端和样板终端。
配方所需源质各 1024 点，实际存于 AE 源质元件，由 TC4 Core 的 AE 直供模式逐点提取。
本组不放源质罐、注魔供应器，与第一组保持距离；地下对称蜡烛用于稳定注魔。
从合成终端请求石英法杖杖芯，在源质终端观察库存下降即可测试。

搭建时使用 `-PpackagedPlaygroundResume=<存档名称> -PpackagedPlaygroundAE=true`。
仅用于首次增加第二套；再次打开同一世界应省略 `packagedPlaygroundAE`，避免重复搭建。
搭建器会拒绝覆盖第二套区域的已有建筑。

搭建器会先通过真实 AE CPU 完成一次验证合成，核对三种源质的精确扣量，再补回验证消耗的源质。
验证期间检查缺源质等待、任务中禁止切换、Provider 身份匹配和任务来源 NBT 保存。
源质吸取默认 8 倍，右键 Provider 左侧最下方的源质按钮可切换 1/2/4/8/16/32 倍。
验证以单次扣量为单位检查空库存、部分库存、充足库存，不假设手动测试世界的库存从未变化。
