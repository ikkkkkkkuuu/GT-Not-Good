# 网页显示屏

可在工作台合成“网页显示屏”，也可从 GTNG 方块创造栏取得。首版适配 Windows，使用本机已安装的 Microsoft Edge 或 Google Chrome，无需 MCEF。

工作台配方（产出 1 块）：

```text
钢板      荧石粉     钢板
1×铜线缆  玻璃板     1×铜线缆
钢板      LV电路     钢板
```

共需 4 个钢板、2 根 1×铜线缆、1 个原版玻璃板、1 个 LV 电路和 1 个荧石粉。钢板、铜线缆和 LV 电路接受相应矿物词典材料，可在 NEI 查看配方；LV 电路不能用设置编号的编程电路代替。

- 右键打开浏览器界面，可输入网址、点击、滚动及输入文字；支持 Ctrl+V 粘贴。
- 使用工具栏 `- / 百分比 / +` 或 Ctrl+滚轮、Ctrl +/- 调整网页大小，范围 25%–300%；点击百分比或按 Ctrl+0 还原。缩小可显示更多内容，放大可增大文字，输出分辨率不变。
- 网页缩放保存在此屏幕的本机浏览器身份中，导航、关闭界面及停止重开后仍保留；编辑地址栏时不触发网页缩放。
- Esc 或“关闭”返回游戏，网页继续显示在方块正面。
- 将同朝向的显示屏排成完整矩形即可自动拼接，最大宽 16 格、高 9 格；右键任意一块操作整屏。
- 大屏共用一个浏览器会话，画面保持 16:9，空余区域留黑边；扩建时保留当前网页和本机登录数据。
- 不完整、带孔或超限的形状按单块显示；拆成互不相连的矩形后，各屏独立。
- 空手潜行右键方块或点击“停止”关闭此屏幕的本机浏览器。
- 默认同时运行 2 个屏幕，距离超过 24 格、区块卸载或退出世界时停止浏览器。

右键显示屏后，点击工具栏的“设置”，可单独调整当前屏幕的分辨率、刷新上限、画质和静音。点击“应用”后重新载入当前网页，保留网址、登录数据和缩放；取消或按 Esc 放弃编辑。其他屏幕不受影响，设置按本机屏幕身份保存。

画面默认 **1920×1080、刷新上限 100 FPS**，为达到 90 FPS 留出余量，可调整以下选项：

| 显示屏设置 | 默认值 | 可选值 |
| --- | --- | --- |
| 分辨率 | 1080P | 1080P（1920×1080）、2K（2560×1440）、4K（3840×2160） |
| 刷新上限 | 100 | 15–100 FPS |
| 画质 | 90 | 60–100 |
| 静音 | 关闭 | 开启或关闭，独立于 Minecraft 主音量 |

分辨率控制输出像素，网页缩放单独控制文字与布局大小。刷新按游戏渲染帧更新；实际帧率受浏览器、硬件、分辨率及游戏帧率影响，不保证最低 90 FPS。视频清晰度和帧率仍需在网站播放器中选择，并受片源和账号权限限制。2K、4K 使用有界并行解码，纹理直接上传解码像素，减少处理等待和内存复制；仍不保证 4K 最低 90 FPS。

模组设置的 `Client` 分类仅保留浏览器环境和总量限制：总开关、浏览器路径、最大会话数及停止距离。浏览器路径在下次启动屏幕时生效。

浏览器数据保存在游戏目录的 `gtnotgood/webscreens/`，按世界或服务器以及屏幕身份分开；拼接成员共享本机浏览器身份。网页、账号登录态及播放进度由各玩家独立保存，不同步给服务器和其他玩家。第一次登录需在屏幕内自行操作；普通桌面浏览器的登录态不会自动导入。全部移除并重新放置方块会产生新的屏幕身份。

已用独立静音会话验证 Bilibili 公共视频播放、鼠标键盘输入和 Cookie 持久保存。账号登录后的内容、会员清晰度和实际声音输出尚未验证。当前不包含多人同步观看。

维护时可运行 `gradlew.bat -I scripts/web-screen-qa.init.gradle runClient17 --no-configuration-cache`。该测试端强制静音并使用专用隐藏窗口助手，结果及截图位于 `build/web-screen-qa/`。
