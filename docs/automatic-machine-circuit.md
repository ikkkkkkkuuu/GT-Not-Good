# AE 样板自动设置单方块编程电路

## 用法

1. 普通 ME 接口或流体接口直接贴着支持虚拟编程电路的 GT 电力单方块机器。
2. 编码加工样板，保留配方的消耗原料、流体和全部产物，删除输入中的编程电路。
3. 把样板放入接口，正常下单。接单时机器会设置配方所需虚拟电路，无电路配方会清空虚拟电路槽。
4. 按原有方式回收产物。电压、洁净室、供电以及机器进料面的限制仍由 GT 处理。

配置文件中的 `GregTech.enableAutomaticMachineCircuit` 默认开启；关闭后恢复 AE 普通投料流程。

## 接单规则

- 使用机器自己的配方表，同时比较物品、流体、NBT、数量比例和全部产物。支持整数倍样板。
- 不把电路作为消耗材料，也不生成可提取的实体电路。
- 相同配方可以在机器加工中继续整批补料，无须等输入清空；已有物品和流体必须仍是该配方的完整批次。
- 切换电路（包括设置或清空虚拟电路）须等当前加工结束，且物品、流体输入全部耗尽。
- 插入前检查整批容量、侧面和覆盖板权限。失败时保留原有电路、输入槽及流体，AE 保留整批资源重试。
- 两个接口可连续投递同一配方，按实际剩余容量逐批接收；不同配方不能混入已有原料。
- 区块重载后若机器正在加工且无法确认原任务，先等机器停止加工，再根据剩料恢复同配方补料。
- 无匹配配方、多个匹配电路、整批超过机器容量时会等待。检查样板并减少单次样板数量；不是自动拆分投料。
- 第一版不支持多方块、蒸汽机器、箱子/管道中转、随机产物、省略副产物的样板，以及需要其他不消耗催化剂的配方。
- 匹配缓存随样板对象释放。运行时替换配方定义后需重启游戏。

## 游戏内验收（待执行）

- 普通接口：同一机器放两个原料相同、产物不同且所需电路不同的样板，交替及同时下单，核对电路与产物。
- 流体接口：分别验证物品加流体输入、纯流体输入及流体产物配方，检查精确 mB 数量。
- 连续补料：加工中分别在输入为空、已有同配方物品及流体时下相同配方，确认立即接收并正确叠加数量；整数倍样板也应识别为同一配方。
- 投料失败：整批容量不足、覆盖板禁止输入、存在异种原料或数量比例错误的剩料时，确认资源留在 AE 且旧电路不变。
- 切换电路：分别在机器加工中但输入为空、机器停止但仍有旧物品或流体时下另一电路的订单，确认等待；加工和剩料均结束后才能切换。
- 重复下单：两侧接口同时下发不同电路的订单，确认串行完成；中途保存退出再进入，确认已有原料及电路保持一致。
- 无电路配方：先执行有电路配方，再执行无电路配方，确认虚拟槽清空。
- 不支持的样板：漏写副产物、保留电路输入或错误产物，确认不投料、不猜号。
- 关闭配置：确认普通 AE 投料恢复；多方块与不支持虚拟电路的机器继续走原路径。

自动化测试覆盖数量匹配和补料准入规则；编译通过不代表上述游戏内集成已验收。
