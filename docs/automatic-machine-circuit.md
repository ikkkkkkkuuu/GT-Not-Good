# AE 样板自动设置单方块编程电路

## 用法

1. 普通 ME 接口或流体接口直接贴着支持虚拟编程电路的 GT 电力单方块机器。
2. 编码加工样板，保留全部消耗原料和流体，产物只填写希望 AE 用于下单的项目，删除输入中的编程电路。可以省略不想让 AE 主动生产的副产物。
3. 把样板放入接口，正常下单。接单时机器会设置配方所需虚拟电路，无电路配方会清空虚拟电路槽。
4. 按原有方式回收产物。电压、洁净室、供电以及机器进料面的限制仍由 GT 处理。

### 虚拟模具

- 标准 MUI2 电力单方块界面在虚拟电路上方增加虚拟模具选择槽，沿用超级样板输入总成的模具、模头、透镜等目录。
- Shift+左键打开可滚动的选择面板，滚轮或左右键切换，Shift+右键清空。手动更换需等机器停止并清空物品、流体输入。
- AE 样板省略不消耗的实体模具；普通和流体接口会同时识别并设置虚拟电路、虚拟模具。无需模具的配方会清空模具设置。
- 同配方、同电路、同模具可以继续补料；改变任一配置须等旧批次加工和输入耗尽。多个电路/模具组合同时匹配时仍拒绝猜选。
- 虚拟模具作为数量为 0 的催化剂参与 GT 配方，不占输入格，不可提取或掉落，随机器方块 NBT 保存。实际消耗的模具、透镜等物品仍需正常供料。
- 现有超级样板输入总成的槽位、存储和界面保持独立。

配置文件中的 `GregTech.enableAutomaticMachineCircuit` 默认开启；关闭后恢复 AE 普通投料流程。

## 接单规则

- 使用机器自己的配方表，同时比较物品、流体、NBT、数量比例和样板声明的产物。支持整数倍样板。每个声明产物的数量必须准确，可以整个省略某种副产物，但不能少填或多填已声明产物的数量。
- 省略副产物只影响 AE 对样板的生产规划；机器仍正常产出全部副产物，仍需安排回收。最终配方检查和连续补料仍比较完整配方，包含未写入样板的副产物。
- 输入按 GT 的矿物词典和替代原料规则验证，不再只认配方展示的代表物品。橡胶环、硅橡胶环等只有在该 GT 配方允许时才可替代；AE 仍负责按样板的替代设置提供材料。
- 用副本模拟原料消耗，确认无多余原料；不会为验证而消耗机器或 AE 的真实库存。概率消耗原料的配方暂不接收。
- 内容相同、电路相同的重复注册配方按同一配方处理，不依赖配方对象是否相同；不同电路仍视为有歧义。
- 不把电路作为消耗材料，也不生成可提取的实体电路。
- 相同配方可以在机器加工中继续整批补料，无须等输入清空；已有物品和流体必须仍是该配方的完整批次。
- 切换电路（包括设置或清空虚拟电路）须等当前加工结束，且物品、流体输入全部耗尽。
- 插入前检查整批容量、侧面和覆盖板权限。失败时保留原有电路、输入槽及流体，AE 保留整批资源重试。
- 两个接口可连续投递同一配方，按实际剩余容量逐批接收；不同配方不能混入已有原料。
- 区块重载后若机器正在加工且无法确认原任务，先等机器停止加工，再根据剩料恢复同配方补料。
- 无匹配配方、多个匹配电路、整批超过机器容量时会等待。检查样板并减少单次样板数量；不是自动拆分投料。
- 第一版不支持多方块、蒸汽机器、箱子/管道中转、随机产物，以及需要模具目录外不消耗催化剂或同时使用多个不同虚拟模具的配方。
- 匹配缓存随样板对象释放。运行时替换配方定义后需重启游戏。

## 游戏内验收（待执行）

### 拒收诊断

日志中搜索 `[AutoCircuit]` 可查看无匹配、材料或电压不符、电路歧义、空机器进料过滤和最终配方不一致的拒收原因。
记录包括机器坐标、原始样板 NBT、实际下发材料，以及最多 8 个相关产物配方。每个加载中的机器最多报告 8 种样板/原因组合，避免 AE 重试刷屏；容量不足和正常等待切换电路保持静默。
这些日志用于定位游戏内差异，不表示已修复钴黄铜板通配样板的拒收问题。

### 验收项目

- 重复配方：卷板机中重复注册的钢锭转钢板配方应能正常接单及连续补料，无须删除重复配方。
- 替代原料：电动泵样板分别使用橡胶环、硅橡胶环和配方允许的其他胶环；验证 AE 实际投递替代物品、混合合法胶环、连续补料及整数倍样板。错误材料、数量及产物应拒收。

- 普通接口：同一机器放两个原料相同、产物不同且所需电路不同的样板，交替及同时下单，核对电路与产物。
- 流体接口：分别验证物品加流体输入、纯流体输入及流体产物配方，检查精确 mB 数量。
- 连续补料：加工中分别在输入为空、已有同配方物品及流体时下相同配方，确认立即接收并正确叠加数量；整数倍样板也应识别为同一配方。
- 投料失败：整批容量不足、覆盖板禁止输入、存在异种原料或数量比例错误的剩料时，确认资源留在 AE 且旧电路不变。
- 切换电路：分别在机器加工中但输入为空、机器停止但仍有旧物品或流体时下另一电路的订单，确认等待；加工和剩料均结束后才能切换。
- 重复下单：两侧接口同时下发不同电路的订单，确认串行完成；中途保存退出再进入，确认已有原料及电路保持一致。
- 无电路配方：先执行有电路配方，再执行无电路配方，确认虚拟槽清空。
- 省略副产物：1 个硅锭 + 9 mB 润滑油的样板只填写 16 个硅晶圆，确认能接单，机器仍产出 4 个硅粉，AE 不以该样板规划硅粉订单。验证完整输出样板、整数倍样板和省略流体副产物的情况。
- 不支持的样板：保留电路输入、错误产物、错误数量或未声明任何产物，确认不投料、不猜号。
- 关闭配置：确认普通 AE 投料恢复；多方块与不支持虚拟电路的机器继续走原路径。

自动化测试覆盖数量匹配和补料准入规则；编译通过不代表上述游戏内集成已验收。

## 虚拟模具开发客户端验证

`gradlew -I scripts/virtual-mold-qa.init.gradle runClient --no-configuration-cache` 会在独立的新建平坦世界中运行检查，完成后自动退出，不打开现有存档。测试模组仅通过测试 classpath 加载，不进入发布 JAR。

已验证：物品/流体 AE 投料自动选模具、加工中同配方补料、阻止旧批次中切换模具、清空后切换、容量不足时恢复输入/流体/模具、原生 GT 查方及物品消耗、NBT 恢复、不产生真实库存模具、拒绝目录外物品、GUI 选择同步到服务端。截图位于 `run/client/screenshots/virtual-mold-qa.png` 和 `virtual-mold-selector-qa.png`。

该检查使用临时注册的确定性配方，验证真实 Forge/GT/AE 接收代码；完整整合包中的各类实际配方及旧 MUI1/自定义界面仍需分别验证。
