GTLAdditions: Dragonators/GTLAdditions, commit 34fb152886164c56a07fc9d1b10e056f0c22b7ab, GPL-3.0-only.
GTLCore: GNSW/GTLCore, commit 6443c848264fb15c90cf50e031f146522616a8b9, LGPL-3.0-only.
GTCEu Modern: GregTechCEu/GregTech-Modern, commit e3844ba943e2388c0856617ae4f8b473a0ae1b64, LGPL-3.0-only.
GTL official modpack: GregTech Leisure 1.4.5.3, CurseForge file 9238465, CC BY-NC-SA 4.0.
Its archive SHA-256 is 1c732d6b124732c3e3aede97f353910fc31873d9e26074891b2ca69dbcdee23b.

Original 73x73x189 station and 5x21x13 module shapes and all unconstrained spaces are preserved as GZIP MBS.
Controller offsets are (36,36,0) and (2,10,0) after the documented row/aisle transformation.
Original casing images, model face assignments, animation metadata, controller fronts and glow layers are retained.
Connected textures are lossless quarter-tile compositions using the existing LDLib port; hermetic sides combine
its original two coincident model layers at native resolution. Code rewrites incompatible Forge/GTCEu APIs for 1.7.10.
Full sources, exact destinations, modifications, licenses and source/target hashes are in STRUCTURE_ASSET_MANIFEST.json.
Independent rendering and item notices are separate. These assets are excluded from the project's general MIT grant.
Reference sources and offline import tools are not compiled or packaged in the distributable JAR.
