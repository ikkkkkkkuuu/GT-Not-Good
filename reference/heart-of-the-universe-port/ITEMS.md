`items-upstream/` 保存原物品声明、`Misc.kt`、两件物品的模型说明与原始贴图，不参加编译或打包。

  不再使用配方加载时固定的 `setNEIDesc`，切换中英文时随当前语言刷新。

## GTNH 获取适配

配方材料核实于实际缓存 `GT5-Unofficial-5.09.54.183-sources.jar`，包括合并在该依赖中的
GoodGenerator、TecTech、GT++ API。没有引用现代 GTLCore/KubeJS 注册项。

| 原始材料 / 机器 | GTNH 映射 |
| --- | --- |
| 192 根无限反物质燃料棒 | 192 个半稳定反物质单元；保留反物质门槛，不以普通核燃料替代 |
| 超立方体 | 时空连续体撕裂器 |
| Cosmic 熔体 | 熔融宇宙中子素 |
| 原始海珀锟熔体 | 原始海珀锟钢基液；双板直接使用原始海珀锟钢 |
| CREON 熔体 | 熔融永恒 |
| MAX 发射器 | UXV 发射器（GTNH 原生最高部件档） |
| 压缩聚变反应堆 UEV | 致密聚变 MK-V |
| 四类终极电池 | 充满的 UEV/UIV/UMV/UxV 电池，各保留 1024 件 |
| 湮灭发电机 / 戴森球 / 高级超能反应堆 | 反物质发电机 / 戴森球群控制器 / 致密聚变 MK-V |
| 创世纪计算 / 创世终极电池 | 超越主机 / 充满的 UxV 电池 |
| 奇点 | 跨维度对齐矩阵；未创建虚假的原版奇点元数据 |

燃料棒用精密组装机最高结构等级（specialValue=4），保留 4 项输入、4 项流体、12000 tick 和
MAX 配方电压。种子转为原生装配线的 16 项输入、4 项各 92160 mB 流体和 11520 tick；
以致密聚变 MK-V 扫描研究代替现代太空组装模块的 SEPMTier=5 限制。

控制器保留 256 台反物质发电机、256 台戴森球群控制器、256 台致密聚变 MK-V、192 个种子和
四类各 1024 件电池等后期门槛，保留 2304000 tick 加工及研究时间。
超过 64 的输入必须经过 `copyAmountUnsafe` 与 `itemInputsUnsafe`，防止原生 `ItemList.get` 截断数量。
原方 UU 物质为 921600000000 mB；按用户要求改用原生 UU 流体，并重新平衡为
16384000 mB（16384 桶）。控制器现为 14 项物品和 4 项流体输入，UU 为第 4 项流体，
直接使用 `Materials.UUMatter`，不再输入 UU 物质单元或消耗空单元。
用量参考 GT5-Unofficial 5.09.54.205 的 `tectech/loader/recipe/ResearchStationAssemblyLine.java:294-297`：
UXV 能源仓每台 64000 mB，取其 256 倍；同文件 838-843 行的 MK4 聚变电脑使用 50000 mB，可作阶段参照。
这是本模组的定制平衡值，不是官方 MAX 标准，也不保留上游的绝对 UU 成本。原始上游源和哈希不变。
其余三项流体保持原数量，Chaos 映射永恒，Hypogen 与超越金属使用同名原生材料。

## 结构件

七种结构件与同用途 GTNH 高阶结构件通过组装机电路 24/25 进行 1:1 可逆换壳；
换壳不改变原生方块及其他机器的结构要求。

| 移植结构件 | 原生等价件 |
| --- | --- |
| 引力子场约束机械方块 | 终极束缚场发生器 |
| 湮灭核心 | 反物质湮灭矩阵 |
| 维度稳定机械方块 | 宇宙织构屏蔽核心 |
| 时间锚定场外壳 | 时空变换机械方块 |
| 维度连接机械方块 | 维度桥生成器 |
| 创生机械方块 | 无限时空能源边界外壳 |
| 戴森部署磁体 | 戴森球群部署单元磁体 |

铼强化能量玻璃由 4 块已有聚变玻璃、16 块铼板、16 张超越金属箔和 576 mB 时空合成 4 块，
在 UHV 组装机中耗时 1200 tick。

物品和配方 Java 适配代码不含现代物品实现。原素材及 GPL 改编代码不属于项目通用 MIT 授权。
单元测试验证燃料和种子均实际消耗、原始 60%/64 件副产物、可运行配方标志与种子的四帧资源布局。
