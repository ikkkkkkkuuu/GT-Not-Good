面向 **GTNH 2.9.0-RC-2**，汇总自 1.6.6 以来的新增内容与修复。

### 新机器与配方

- **奈亚拉托提普之触**：移植 165×48×49 原结构、连纹和动画，接入参数仓、三类执行核心及输出账本，提供控制器与十四类构件获取配方。装配模式统一包含全部等级原生装配线配方，支持无序输入与 ME 样板总成供料，本机不要求研究介质；电路装配不要求印刻。原生机器与控制器获取方的研究要求保持不变，未移植 GTO 专属电路、无人机和终极电池支线。
- **大型熔炉与并行控制仓**：新增 IV–MAX 十级可调倍率并行仓，共用 Ω 线程仓，支持多配方批处理、满输出保护、输出堵塞与断电恢复。结构直接使用 GTNH 焦炉砖与耐火砖；接入 NEI 原生烧制页和 U 查询，补齐并行仓动画元数据，正面透明边框正确叠加机壳底图。
- **末晶谐振器**：新增 LV–MAX 十四级，利用顶面的末影水晶向机主无线电网发电，支持顶面放置、停机、拆机结算与存档恢复。
- **碎片世界采集器**：新增 ULV 单方块，将十六个维度资源表适配为 239 条配方，使用不消耗的 GTNH 维度展示方块选择资源池；沿用原生单方块自动输出和 Shift 选面，支持大流体数量与存档恢复。上游独有材料的替代范围见仓库移植说明。

### 合成、界面与显示

- **量子合成**：移植 GTNL 量子算法、循环视图、计算超时、材料变体配额、样板优化和名称输入改进。量子模式默认关闭，有量子 CPU 时可切换；保留量子计算机零耗能、大批量派单和同 tick 独立 CPU 分配，补齐服务端及可选模组加载检查。
- **运行效果**：超导电磁工厂的中部 233 个方块运行时旋转，外围静止，实际结构方块保留；正确处理停机、资源重载及卸载。触手补齐运行部件联动与原动画渐变，共用的维度桥接构件同时获得渐变修复。
- **模式与按钮**：现代多方块统一使用可滚动模式列表，普通点击选择后保留列表、Shift 点击选择后关闭；标准按钮统一为 16×16，修正状态图标和边框取样。新增机器 GUI 拆分为独立类，保持同步与存档行为。
- **卫星工厂与猎光号**：完善四级卫星各自的配方池 tooltip 与模式列表，最短批次时间移入并行设置面板；物品和流体产出保留主界面显示，批次、已用/总线程等通过 Waila 服务端快照显示。猎光号主站统计信息移至 Waila。
- **超时空装配 NEI**：合并重复分类，保留单一装配配方池与独立电路池；显示完整物品、流体输入，移除本机不需要的研究/印刻栏。保留旧模式存档迁移。

### 开发与验证

- 开发和构建使用 **JDK 25 + JVM Downgrader**，生成 Java 8 基础字节码与面向 17/21/25 的多版本 JAR，由现有 GTNHLib 提供兼容 API；没有升级整合包或模组依赖。
- 修复首次降级时测试被误判 `NO-SOURCE`，网络回归使用降级输出；完善 Windows 构建脚本、构建缓存、来源许可证、开发文档与 QA 入口。
- 本地完整构建、Spotless、Checkstyle 通过；单元测试 705 项（704 通过、1 项既有跳过），网络回归 12 项通过。现代 Java 定向测试分别在 Java 8/17/21/25 通过，Java 25 客户端及独立服务端量子 QA 通过；大型熔炉最新透明正面在 Java 8 客户端通过。各机器其他实机覆盖和未覆盖范围见仓库测试文档，不代表整合包全部场景均已验证。
